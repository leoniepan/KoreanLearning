# 발음·동사 연습장 — 韓文發音規則與動詞練習帳

配合世宗韓國語 1A～1B 第2課的自學網頁：

- **發音規則**：收音代表音、連音、ㅎ 脫落／激音化、硬音化、鼻音化、流音化、口蓋音化，共 8 步，附例詞、例句與跟讀練習
- **發音測驗**：選正確發音、判斷規則、聽音選字
- **動詞・形容詞**：現在式、過去式、未來式、冠形詞形變化表，附發音、例句與變化說明；可自行新增單字
- **變化測驗**：選變化、句子填空、聽音判斷時態、選發音、中韓配對

朗讀使用瀏覽器內建的韓文語音（Web Speech API）。學習進度與自訂單字存在瀏覽器的 localStorage。

## 部署

單一 `index.html`，在 Settings → Pages 選擇 `main` 分支、`/ (root)` 即可。
